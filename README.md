# Buddy Keynote

Éditeur de présentations STH dans le navigateur. Buddy orchestre chaque
transition de scène et chaque animation de texte.

## Développement

```bash
npm install
npm run dev
```

Le deck est sauvegardé localement dans le navigateur. Il peut aussi être exporté
et réimporté au format `*.buddydeck.json`.

## Raccourcis

- `⌘/Ctrl + Entrée` : présenter depuis la diapositive sélectionnée.
- `⌘/Ctrl + D` : dupliquer la diapositive.
- `⌘/Ctrl + Z` / `⇧ + ⌘/Ctrl + Z` : annuler / rétablir.
- `⌥/Alt + ↑` / `⌥/Alt + ↓` : réordonner la diapositive.
- En présentation : `Espace` ou les flèches pour naviguer, `B` pour l’écran
  noir, `F` pour le plein écran et `Échap` pour quitter.
